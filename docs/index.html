學習路徑

照順序讀，每一站只講一件事。每頁底部都有「下一站」。

  1. 01 AI agent 是什麼 一個以語言模型為大腦，能自己規劃、使用工具、記住事情來完成任務的系統。
  2. 02 基本積木：加了配備的 LLM 在語言模型外面加上檢索、工具與記憶，就是所有 agent 系統的最小單位。
  3. 03 Agent 循環：想、做、看 Agent 不是一次回答完，而是重複「想 → 做 → 看結果」直到完成。
  4. 04 ReAct：邊想邊做 讓模型把「想法」和「行動」交錯寫出來的做法，是 agent 循環的原型。
  5. 05 工具：讓模型能動手 工具是 agent 能呼叫的外部功能，用來查資料、執行程式或操作其他系統。
  6. 06 記憶：短期與長期 短期記憶是模型當下看得到的內容；長期記憶存在外部，需要時再查回來。
  7. 07 規劃：拆解與反思 Agent 把大任務拆成小步驟，並在過程中回頭檢討、修正做法。
  8. 08 Workflow 與 agent 的差別 Workflow 的步驟由人事先寫好；agent 的步驟由模型自己邊做邊決定。
  9. 09 五種 workflow 模式 串接、分流、平行、指揮分工、評分修正：五種把 LLM 呼叫組起來的固定流程。
  10. 10 多個 agent 一起工作 任務太複雜時可以拆給多個 agent：由一位主管指揮，或彼此交接。
  11. 11 MCP：工具的共通插頭 一套開放標準，讓各種 AI 應用用同一種方式接上外部的資料與工具。
  12. 12 AGENTS.md：給 agent 的專案說明書 放在專案裡的一份 Markdown，告訴 AI 這個專案的規則、結構與做事方式。
  13. 13 護欄與人類把關 用多層檢查限制 agent 能做的事，並在高風險或一直失敗時交給真人。

基礎Agent 是什麼、由哪些零件組成

運作方式Agent 怎麼一步一步把事情做完

  • Agent 循環：想、做、看Agent 不是一次回答完，而是重複「想 → 做 → 看結果」直到完成。
  • ReAct：邊想邊做讓模型把「想法」和「行動」交錯寫出來的做法，是 agent 循環的原型。
  • 工具：讓模型能動手工具是 agent 能呼叫的外部功能，用來查資料、執行程式或操作其他系統。
  • 記憶：短期與長期短期記憶是模型當下看得到的內容；長期記憶存在外部，需要時再查回來。
  • 規劃：拆解與反思Agent 把大任務拆成小步驟，並在過程中回頭檢討、修正做法。

設計模式什麼時候用固定流程、什麼時候放手讓模型決定

  • Workflow 與 agent 的差別Workflow 的步驟由人事先寫好；agent 的步驟由模型自己邊做邊決定。

生態與工具讓 agent 接上外部世界與專案規則的標準

  • MCP：工具的共通插頭一套開放標準，讓各種 AI 應用用同一種方式接上外部的資料與工具。
  • AGENTS.md：給 agent 的專案說明書放在專案裡的一份 Markdown，告訴 AI 這個專案的規則、結構與做事方式。
  • LLM Wiki：讓 AI 維護的知識庫人挑資料、AI 把資料整理成互相連結的 Markdown 頁面，並持續更新。

風險與限制放手之前要先想好的事
