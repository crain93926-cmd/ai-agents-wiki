護欄與人類把關

用多層檢查限制 agent 能做的事，並在高風險或一直失敗時交給真人。

讓 agent 自己動手做事，就像讓新人獨立作業：需要先講好哪些事不能做、哪些事要先問過主管。護欄就是這些規定的技術版本。

多層護欄

沒有哪一種護欄單獨就夠，所以要多層搭配。常見的種類有：判斷問題是否在服務範圍內的相關性分類器、偵測惡意提示的安全分類器、個資過濾、內容審核、依風險高低為工具分級的工具防護、黑名單與長度限制等規則式防護，以及輸出驗證。建議先從資料隱私與內容安全做起，再依實際遇到的狀況增加。OpenAI 2025

什麼時候交給真人

有兩種情況應該讓人接手：一是超過失敗門檻，例如 agent 多次都無法理解使用者的意圖；二是高風險動作，例如取消訂單、核准大額退款、付款。在 agent 的可靠度被驗證之前，這些動作都應該先經過人。OpenAI 2025

檢查點與測試

Agent 也可以在預先設好的檢查點暫停，等人確認後再繼續。上線之前，建議先在隔離的環境充分測試，因為自主運作時錯誤會累積。Anthropic 2024
