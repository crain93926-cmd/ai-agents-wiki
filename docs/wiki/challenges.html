Agent 目前的限制

上下文有限、長程規劃容易走偏、輸出不一定照格式，是 agent 常見的三個難題。

Agent 聽起來很厲害，但它有幾個到現在都還在努力解決的弱點。知道弱點在哪裡，才知道什麼事可以交給它。

三個常見難題

  • 上下文長度有限：歷史紀錄、指示、工具回傳的內容都要擠進同一個視窗，放不下就得取捨。
  • 長程規劃困難：步驟一多，模型容易偏離原本的計畫；遇到沒預料到的錯誤時，也不容易像人一樣調整。
  • 自然語言介面不可靠：模型的輸出可能格式不對，或沒有照指示做，所以程式要花很多力氣解析與檢查它的輸出。

以上三點整理自 2023 年的總覽文章。Weng 2023

自主的代價：成本與錯誤累積

讓模型自己決定步驟，通常比較慢、比較貴。而且每一步都建立在上一步的結果上，前面的小錯可能一路累積成大錯。因此建議先在隔離的測試環境（沙盒）裡充分測試，並搭配護欄。Anthropic 2024
