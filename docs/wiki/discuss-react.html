討論：ReAct 論文

讀入 ReAct 論文（2022）之前的重點提案

這篇的重點

  1. 把「想」和「做」交錯進行：Thought → Action → Observation，重複到完成。
  2. 「做」讓模型能拿到外部的新資訊；「想」讓模型能根據新資訊調整計畫。
  3. 過程寫得出來，所以人看得懂模型為什麼這樣做。
  4. 它是一種提示方式，不是新模型。
  5. 實驗數字：ALFWorld 絕對成功率 +34%、WebShop +10%，只用一到兩個範例。
