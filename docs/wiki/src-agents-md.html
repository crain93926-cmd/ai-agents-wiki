這篇在講什麼

AGENTS.md 格式的官方網站，說明這個檔案是什麼、該寫什麼、哪些工具支援。

重點

  • AGENTS.md 是開放的純 Markdown 格式，給會寫程式的 agent 專案層級的指引，沒有必填欄位。見 AGENTS.md：給 agent 的專案說明書。
  • README 給人看；AGENTS.md 放 agent 需要的建置步驟、測試指令與慣例。
  • 可以在子資料夾各放一份，離被編輯檔案最近的優先；使用者在對話中的明確指示優先於一切。
  • 網站列出多種支援的工具，並說明由 Linux Foundation 旗下的 Agentic AI Foundation 維護。
  • 網站在讀取當天（2026-11-16）寫有超過 60,000 個開源專案使用。

這篇資料的限制

  • 推廣這個格式的官方網站，沒有討論缺點。
  • 採用數字是網站自己的說法，會隨時間改變。
