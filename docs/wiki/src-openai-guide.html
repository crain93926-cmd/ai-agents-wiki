這篇在講什麼

OpenAI 根據客戶部署的經驗，寫給第一次要做 agent 的產品與工程團隊的指南。從「什麼是 agent」一路講到護欄與人類介入。

重點

  • 定義：agent 是能代替使用者獨立完成任務的系統，由 LLM 管理流程並使用工具。見 AI agent 是什麼。
  • 適合 agent 的三類流程：需要複雜判斷、規則難以維護、依賴非結構化資料。見 Workflow 與 agent 的差別。
  • 三個核心元件是模型、工具、指示；工具分資料、行動、協調三種。見 工具：讓模型能動手。
  • 單一 agent 的執行迴圈有四種離開條件。見 Agent 循環：想、做、看。
  • 多 agent 有 manager 與 decentralized handoff 兩種模式，但建議先把單一 agent 用到極限。見 多個 agent 一起工作。
  • 護欄要多層搭配，並在失敗過多或高風險動作時交給真人。見 護欄與人類把關。

這篇資料的限制

  • 廠商指南，範例以 OpenAI 自家的 SDK 為主。
