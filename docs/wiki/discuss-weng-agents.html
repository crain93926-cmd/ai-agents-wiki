討論：Lilian Weng〈LLM Powered Autonomous Agents〉

讀入 Lilian Weng 2023 年 agent 總覽文章之前的重點提案

這篇的重點

  1. 一個好記的架構：LLM 是大腦，外加規劃、記憶、工具三個零件。
  2. 規劃 = 拆解任務 + 反思修正。
  3. 記憶分短期（上下文視窗內）與長期（外部資料庫，用檢索取回）。
  4. 工具讓模型拿到權重裡沒有的東西：最新資訊、執行程式、專有資料。
  5. 三個挑戰：上下文有限、長程規劃困難、自然語言介面不可靠。

預計新增的頁面

  • Weng 2023：來源頁
  • AI agent 是什麼：先放這篇的「大腦＋三零件」架構，之後的來源再補上不同機構的定義
  • 規劃：拆解與反思、記憶：短期與長期、工具：讓模型能動手：三個零件各一頁
  • Agent 目前的限制：限制與挑戰

預計更新的頁面

  • ReAct：邊想邊做：補上 ReAct 在整個架構中屬於「反思修正」這一類

和既有內容的關係
