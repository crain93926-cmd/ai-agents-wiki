下一步：把這套流程做成自動化的 agent

期末專案構想 WikiDeck：輸入一個主題，自動建立 LLM Wiki 並產出教學簡報。

這個網站目前是「人下指令、AI 照 AGENTS.md 一步一步做」。期末專案要把同一張流程圖寫成程式，讓它可以對任何主題重跑。目前的流程見 這個網站的製作流程。

構想

WikiDeck：使用者輸入主題、對象與想讀的來源數量，系統自動找資料、建立 LLM Wiki、通過檢查後產出一份教學簡報網站。人只在三個地方把關：確認來源清單、確認每篇的重點、確認發布。

和現在的差別

現在（手動版，已完成） 期末專案（自動版）
誰推動流程 人在對話中一步一步下指令 程式依流程圖自動往下走
檢查 check.py 三段檢查，人看截圖 同樣的 check.py，再加上 LLM 評審與視覺模型看截圖
人類把關 沒有固定的暫停點 三個固定的暫停點，介面上按確認才繼續
換主題 要重新下一輪指令 輸入新主題即可重跑

為什麼可行

  • 每個節點都已經用手動方式跑通過一次：七篇來源、十五個概念頁、二十張投影片。
  • 三段檢查與建置已經是可以獨立執行的程式，不需要重寫。
  • 剩下的工作是把「人對 AI 下的指令」改成程式呼叫，並把流程圖寫成狀態圖。這個流程屬於固定流程而不是自由行動的 agent，理由見 Workflow 與 agent 的差別；用到的模式見 五種 workflow 模式，暫停點的設計依據見 護欄與人類把關。
