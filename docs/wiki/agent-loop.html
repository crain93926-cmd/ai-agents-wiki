Agent 循環：想、做、看

Agent 不是一次回答完，而是重複「想 → 做 → 看結果」直到完成。

一般的聊天是「問一句、答一句」。Agent 的做事方式比較像煮一道沒煮過的菜：看食譜、做一步、嚐味道、再決定下一步。

基本形狀

循環有三步：先想下一步要做什麼，再實際去做，然後看做出來的結果。看完之後回到第一步，根據新的結果再想一次。這個「想法 → 行動 → 觀察」的寫法最早由 ReAct：邊想邊做 清楚地提出。ReAct 2022

每一步都要看到真實結果

Agent 可以說是「在迴圈裡根據環境回饋使用工具的 LLM」。關鍵在回饋：每做一步，都要從環境拿到真實的結果（例如工具回傳的內容、程式執行的輸出），才能判斷有沒有進展。只靠模型自己想像結果，錯誤會越滾越大。Anthropic 2024

什麼時候停

循環通常在任務完成時結束。實務上還會另外設定停止條件，例如最多跑幾輪，避免停不下來。Agent 也可以在預先設好的檢查點、或是自己卡住的時候暫停，回頭問人。Anthropic 2024

OpenAI 的指南列了四種離開迴圈的條件：呼叫了代表「最終輸出」的工具、模型回覆時沒有再呼叫任何工具、發生錯誤、達到最大回合數。OpenAI 2025
