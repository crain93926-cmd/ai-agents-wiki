這篇在講什麼

一份描述做法的想法文件：與其每次提問都重新檢索原始文件，不如讓 LLM 把知識整理成一個持續更新的 wiki。

重點

  • 三層結構（原始來源、wiki、schema）與三種操作（ingest、query、lint）。見 LLM Wiki：讓 AI 維護的知識庫。
  • 規則檔（CLAUDE.md 或 AGENTS.md）在這個模式裡是 schema。見 AGENTS.md：給 agent 的專案說明書。
  • index.md 當目錄、log.md 當時間軸。
  • 人挑來源與提問，LLM 做整理與維護。
  • 本站依這個模式製作，流程見 這個網站的製作流程。

這篇資料的限制

  • 想法文件，沒有程式碼也沒有實驗數據。
  • 作者說的「靠目錄就夠、不需要向量檢索」以中等規模為前提。
