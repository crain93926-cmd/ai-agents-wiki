讀入 AGENTS.md 官方網站之前的重點提案

這篇的重點

  1. AGENTS.md 是給 coding agent 看的 README：純 Markdown、沒有必填欄位。
  2. README 給人看，AGENTS.md 給 agent 看，兩者分工。
  3. 常見內容：專案概觀、建置與測試指令、風格、安全注意事項。
  4. 可以分層放；最近的那一份優先，使用者當下的指示最優先。
  5. 許多工具支援，由 Linux Foundation 旗下的基金會維護。

預計新增的頁面

  • agents.md：來源頁
  • AGENTS.md：給 agent 的專案說明書：AGENTS.md 是什麼、為什麼 agent 需要它

預計更新的頁面

  • 無。

和既有內容的關係

  • 補充：前面的來源談的是 agent 的「指示」要寫清楚（OpenAI 2025 的三元件之一）；AGENTS.md 是把「專案層級的指示」放進檔案的一種慣例。
